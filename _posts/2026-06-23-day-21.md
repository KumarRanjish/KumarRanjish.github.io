what_i_learned: |
   Today was an important and productive day in my research project. I focused on preparing my cleaned BACE1 dataset for baseline
   QSAR modeling. Since my assigned datase specifically related to BACE1 activity prediction, I worked only with the BACE1 dataset
   and did not include BBB, AChE, or ASK1 data in this stage.

   The cleaned BACE1 dataset contains standardized SMILES, pIC50 values, activity labels, and molecular descriptor information such 
   as molecular weight, TPSA, hydrogen bond donor count, and hydrogen bond acceptor count. I learned that the SMILES column is very
   important because it represents the chemical structure of each compound. However, machine learning models cannot directly understand
   SMILES as text, so the molecules need to be converted into numerical features.

   For this purpose, I used Morgan fingerprints. I learned that Morgan fingerprints help represent molecular structures as numerical vectors.
   These fingerprints capture important structural patterns in the compounds, which can then be used by machine learning models to predict biological 
   activity. This step helped me understand how chemical information is transformed into a format suitable for QSAR modeling.

   After generating Morgan fingerprints, I worked on baseline supervised machine learning models. For classification, the goal was 
   to predict whether each compound is active or inactive against BACE1. I used five baseline classification models: Logistic Regression, Decision 
   Tree, Random Forest, Support Vector Machine, and Gradient Boosting. These modelsn were selected because they provide a strong starting point for
   comparing QSAR performance.

   I also prepared regression models to predict the continuous pIC50 values of the compounds. For regression, I used Ridge Regression, Decision
   Tree Regressor, Random Forest Regressor, Support Vector Regressor, and Gradient Boosting Regressor. This allowed me to understand both types
   of QSAR tasks: classification for active/inactive prediction and regression for activity strength prediction.

   Another important part of today’s work was understanding model evaluation. For classification models, I learned how to evaluate performance 
   using confusion matrix, accuracy,precision, recall, F1-score, balanced accuracy, ROC-AUC, and PR-AUC. I also learned that PR-AUC is especially 
   useful when a dataset is imbalanced. For regression models, I learned about mean absolute error, root mean squared error, R² score, and 
   predicted-versus-observed plots.

   Overall, today helped me understand the full baseline QSAR workflow more clearly. I learned how my cleaned BACE1 dataset can be used to generate
   molecular fingerprints, train baseline machine learning models, evaluate their performance, and rank compounds based on predicted BACE1 activity.
   This work will be useful for the next stage of the project,where I can compare model performance, improve the models, and identify promising candidate
   compounds for Alzheimer’s disease drug discovery.
